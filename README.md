# Планер — студенческий планировщик учёбы

Десктопное и мобильное приложение для планирования учёбы: расписание пар, светофор дедлайнов и почасовой план на каждый день с учётом сна и постоянных дел.

## 1. Идея проекта

Студент ведёт всю учёбу в одном месте:
- видит актуальное **расписание пар** своей учебной группы;
- управляет **большими заданиями** (с дедлайнами и бессрочными);
- самостоятельно расставляет **задачи по часам** внутри каждого дня с учётом времени сна и еженедельных постоянных дел;
- ориентируется по **светофору дедлайнов**, который подсвечивает срочность каждого задания от красного к зелёному.

Интерфейс адаптирован под десктоп (боковая панель навигации, двухколоночные дашборды, недельные таблицы и модальные окна) и мобильные устройства (нижняя панель вкладок `TabBar`, вертикальные списки и шторки `Sheet`).

### Светофор дедлайнов

Все списки дедлайнов автоматически сортируются сверху вниз от самых срочных к дальним, а дата дедлайна отображается в бейдже соответствующего цвета:
- 🔴 **Красный** (`#E5484D` / `#FDE6E6`) — до дедлайна **0–5 дней** (включая просроченные);
- 🟡 **Жёлтый** (`#F2B01E` / `#FFF2CC`) — до дедлайна **6–14 дней**;
- 🟢 **Зелёный** (`#2FA563` / `#DFF5E7`) — до дедлайна **более 14 дней**;
- ⚪ **Выполнено** — зачёркнутый текст и подпись *«Исчезнет через 12 ч»* (отметка синхронизируется во всех разделах).

## 3. Структура приложения и экраны

### Вход, регистрация и первый запуск (`/login`, `/register`, `/onboarding`)
- Регистрация и вход выполняются по почте и паролю (на десктопе — двухколоночный экран с описанием возможностей сервиса слева и формой справа).
- После входа проверяется заполненность профиля (`AuthGate`): если не указаны обязательные поля (**Имя** и **Учебная группа**), открывается экран первичного заполнения профиля (`/onboarding`), где также можно сразу настроить режим сна, добавить постоянные дела и подключить ссылку на расписание.

### 1. Главная (`/`)
- Персональное приветствие в зависимости от времени суток и текущая дата.
- **Левая колонка — «Задачи на сегодня»**: единый хронологический таймлайн дня, объединяющий пары, запланированные задачи и постоянные дела со счётчиком событий.
- **Правая колонка — «Мои дедлайны» и «Бессрочные задания»**: списки активных заданий с чекбоксами выполнения, всплывающими комментариями, кнопками «Ред.» и быстрым переходом в раздел «Все задания».

### 2. Мои планы (`/plans` и `/day`)
Работает в три шага:
1. **Неделя целиком (`/plans`)**:
   - На десктопе — 7-колоночная сетка недели (Пн–Вс), на мобильных — список карточек по дням.
   - Переключение недель стрелками и быстрый возврат кнопкой «Сегодня».
   - Фильтры **«Отображать пары»** и **«Отображать дела»** (включает задачи и постоянные дела) + цветовая легенда.
2. **Страница дня (`/day?date=YYYY-MM-DD`)**:
   - Открывается по клику на любой день недели.
   - Слева — подробное расписание выбранного дня (блоки сна, пары, задачи с комментариями и постоянные дела).
   - Справа (на десктопе) — карточки «Дедлайны» и «Бессрочные задания» с возможностью отмечать выполнение и редактировать задания не покидая страницу дня.
3. **Окно «+ Новая задача»**:
   - Позволяет запланировать на выбранный день либо задание из существующего списка (разделённого на группы *«Бессрочные»* и *«С дедлайном»*), либо **разовую задачу только на этот день**.
   - Автоматически рассчитывает и показывает продолжительность выбранного слота (например, *«2 часа · с 12:40 до 14:40»*). Задачу можно поставить на любое время, даже поверх сна или постоянного дела.

### 3. Все задания (`/assignments`)
- Переключатель вкладок **«С дедлайнами»** и **«Бессрочные»** со счётчиками количества заданий и подсказкой сортировки.
- В режиме «С дедлайнами» на десктопе рядом с бейджем даты отображается точное время дедлайна (`23:59`, `18:00`).
- Модальное окно **«Новое задание» / «Редактирование задания»**: название, дата и время дедлайна, чекбокс «Без дедлайна» (отключающий поля даты и времени), комментарий с лимитом `0 / 300` и кнопка удаления задания.

### 4. Пары (`/schedule`)
- На десктопе — полная недельная таблица расписания (Пн–Сб) по временным слотам звонков; на мобильных — переключатель по дням недели.
- В каждой карточке отображаются предмет, корпус и аудитория, тип занятия и бейдж **«Изменено»** (при обновлении пары).
- Если в расписании произошли изменения, в навигации рядом с пунктом «Пары» загорается красная точка.
- Кнопка **«Загрузить расписание»** открывает модальное окно подключения ссылки на Google Таблицу с расписанием модуля (`POST /sources`).

### 5. Профиль (`/profile`)
- **Личные данные**: редактирование имени, выбор учебной группы из каталога (`GET /groups`) и настройка времени сна (отбой и подъём).
- **Другие дела**: список еженедельных постоянных дел с возможностью добавления (`+ Добавить дело`), редактирования дней недели и времени, а также удаления.
- Подключение новой ссылки на расписание и выход из аккаунта.

## 4. Стек технологий и дизайн-система

- **Фреймворк**: [Next.js 16](https://nextjs.org/) (App Router, Static Export для совместимости с Tauri) + React 19 + TypeScript
- **Стилизация и UI**: Tailwind CSS v4, `@base-ui/react`, `shadcn/ui`, иконки `lucide-react`, шрифт `Inter` (шаг сетки 4 px)
- **Состояние и работа с данными**: TanStack React Query v5, React Hook Form + Zod v4, `date-fns`
- **Десктоп- и мобильная сборка**: [Tauri v2](https://v2.tauri.app/) (`src-tauri/`)

## 5. Запуск и разработка

### Переменные окружения
По умолчанию фронтенд обращается к бэкенду по адресу `https://personalplanner-ybpm.onrender.com`. При необходимости переопределить адрес API создайте файл `.env.local`:

```env
NEXT_PUBLIC_API_URL=https://personalplanner-ybpm.onrender.com
```

### Команды

```bash
# Установка зависимостей
bun install

# Запуск dev-сервера (http://localhost:3000)
bun run dev

# Проверка линтером и форматирование
bun run lint
bun run fmt:check

# Сборка статического бандла Next.js
bun run build

# Запуск в окружении Tauri
bun run tauri dev
```

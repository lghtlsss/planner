# Планер — студенческий планировщик учёбы

Десктопное и мобильное приложение для планирования учёбы: расписание пар, светофор дедлайнов и почасовой план на каждый день с учётом сна и постоянных дел.


---

## Как установить и начать пользоваться (для обычных пользователей)

Устанавливать Python, Bun, Docker или скачивать исходный код не нужно. Готовые версии приложения доступны на странице релизов проекта:

**[Скачать Планер](https://github.com/lghtlsss/planner/releases/latest)**

### Windows
1. На странице релиза в разделе **Assets** скачайте `Personal.Planner_1.0.0_x64-setup.exe`.
2. Запустите скачанный файл и следуйте инструкциям установщика.
3. Откройте **Personal Planner** через меню «Пуск» или ярлык приложения.

### Android
1. На странице релиза в разделе **Assets** скачайте `app-universal-release.apk`.
2. Откройте APK-файл из папки загрузок и подтвердите установку. Android может попросить разрешить установку приложений из используемого источника — при необходимости разрешите её для браузера или файлового менеджера, из которого открываете файл.
3. После установки запустите **Personal Planner**.

### Первый запуск
1. Подключитесь к интернету — приложению требуется сеть для работы с аккаунтом и синхронизации данных.
2. Создайте аккаунт с помощью электронной почты и пароля либо войдите в существующий аккаунт.
3. При первом входе укажите имя и выберите учебную группу. Время сна и постоянные дела можно настроить сразу или позднее в профиле.
4. Чтобы подключить расписание, откройте в профиле или разделе «Пары» пункт **«Загрузить расписание»** и вставьте ссылку на Google Таблицу с расписанием. После успешного подключения выберите свою учебную группу.
5. Добавляйте задания, отмечайте их выполнение и составляйте план на неделю или на конкретный день.

Если список учебных групп пуст или при подключении расписания появляется ошибка, возможно, на сервере не настроен импорт расписаний. В таком случае обратитесь к человеку, который поддерживает используемый экземпляр Планера.

В текущем публичном релизе доступны сборки для **Windows** и **Android**. Установщиков для macOS, Linux и iOS в релизе пока нет.

## 1. Идея проекта

Студент ведёт всю учёбу в одном месте:
- видит актуальное **расписание пар** своей учебной группы;
- управляет **большими заданиями** (с дедлайнами и бессрочными);
- самостоятельно расставляет **задачи по часам** внутри каждого дня с учётом времени сна и еженедельных постоянных дел;
- ориентируется по **светофору дедлайнов**, который подсвечивает срочность каждого задания от красного к зелёному.

Интерфейс адаптирован под десктоп (боковая панель навигации, двухколоночные дашборды, недельные таблицы и модальные окна) и мобильные устройства.

## 2. Основные понятия и цветовая кодировка

| Понятие | Описание | Пример |
| :--- | :--- | :--- |
| **Задание**| Большая учебная работа с конкретной датой и временем сдачи. Отображается в разделе «Все задания», на «Главной» и на странице дня. | Проект по ОРГ, ДЗ по мат. анализу |
| **Бессрочное задание** | Задание без дедлайна (отмечен флаг «Без дедлайна»). Не имеет даты и цветового бейджа. | Разобрать конспекты за семестр |
| **Задача** | Запланированный временной слот в конкретный день для работы над заданием из списка дедлайнов. | 15:00–17:00 · ДЗ по мат. анализу |
| **Разовая задача** | Задача только на один конкретный день с временем начала и окончания. Не попадает в общие списки заданий. | 15:00–16:00 · Психологический тест |
| **Пара** | Учебное занятие из расписания группы (предмет, тип занятия, корпус и аудитория). | 09:30–11:00 · Мат. анализ (к. 2, ауд. 214) |
| **Постоянное дело** | Еженедельно повторяющееся занятие по выбранным дням недели. Настраивается в профиле. | Секция (Вт, Чт · 18:00–20:00) |
| **Сон** | Время отбоя и подъёма пользователя. Отображается в начале и конце расписания дня. | Сон · до 07:00 / Сон · с 23:00 |
| **Комментарий** | Заметка пользователя к заданию (до 300 символов). Открывается при наведении курсора на десктопе или по нажатию на мобильном устройстве. | «10–15 страниц, реформы Петра I» |

### Светофор дедлайнов

Все списки дедлайнов автоматически сортируются сверху вниз от самых срочных к дальним, а дата дедлайна отображается в бейдже соответствующего цвета:
- 🔴 **Красный** — до дедлайна **0–5 дней** (включая просроченные);
- 🟡 **Жёлтый** — до дедлайна **6–14 дней**;
- 🟢 **Зелёный** — до дедлайна **более 14 дней**;
- ⚪ **Выполнено** — зачёркнутый текст и подпись *«Исчезнет через 12 ч»* (отметка синхронизируется во всех разделах).

## 3. Структура приложения и экраны

### Вход, регистрация и первый запуск
- Регистрация и вход выполняются по почте и паролю (на десктопе — двухколоночный экран с описанием возможностей сервиса слева и формой справа).
- После входа проверяется заполненность профиля: если не указаны обязательные поля (**Имя** и **Учебная группа**), открывается экран первичного заполнения профиля, где также можно сразу настроить режим сна, добавить постоянные дела и подключить ссылку на расписание.

### 1. Главная
- Персональное приветствие в зависимости от времени суток и текущая дата.
- **Левая колонка — «Задачи на сегодня»**: единый хронологический таймлайн дня, объединяющий пары, запланированные задачи и постоянные дела со счётчиком событий.
- **Правая колонка — «Мои дедлайны» и «Бессрочные задания»**: списки активных заданий с чекбоксами выполнения, всплывающими комментариями, кнопками «Ред.» и быстрым переходом в раздел «Все задания».

### 2. Мои планы
Работает в три шага:
1. **Неделя целиком**:
   - На десктопе — 7-колоночная сетка недели (Пн–Вс), на мобильных — список карточек по дням.
   - Переключение недель стрелками и быстрый возврат кнопкой «Сегодня».
   - Фильтры **«Отображать пары»** и **«Отображать дела»** (включает задачи и постоянные дела) + цветовая легенда.
2. **Страница дня**:
   - Открывается по клику на любой день недели.
   - Слева — подробное расписание выбранного дня (блоки сна, пары, задачи с комментариями и постоянные дела).
   - Справа (на десктопе) — карточки «Дедлайны» и «Бессрочные задания» с возможностью отмечать выполнение и редактировать задания не покидая страницу дня.
3. **Окно «+ Новая задача»**:
   - Позволяет запланировать на выбранный день либо задание из существующего списка (разделённого на группы *«Бессрочные»* и *«С дедлайном»*), либо **разовую задачу только на этот день**.
   - Автоматически рассчитывает и показывает продолжительность выбранного слота (например, *«2 часа · с 12:40 до 14:40»*). Задачу можно поставить на любое время, даже поверх сна или постоянного дела.

### 3. Все задания
- Переключатель вкладок **«С дедлайнами»** и **«Бессрочные»** со счётчиками количества заданий и подсказкой сортировки.
- В режиме «С дедлайнами» на десктопе рядом с бейджем даты отображается точное время дедлайна (`23:59`, `18:00`).
- Модальное окно **«Новое задание» / «Редактирование задания»**: название, дата и время дедлайна, чекбокс «Без дедлайна» (отключающий поля даты и времени), комментарий и кнопка удаления задания.

### 4. Пары
- На десктопе — полная недельная таблица расписания (Пн–Сб) по временным слотам звонков; на мобильных — переключатель по дням недели.
- В каждой карточке отображаются предмет, корпус и аудитория, тип занятия и бейдж **«Изменено»** (при обновлении пары).
- Если в расписании произошли изменения, в навигации рядом с пунктом «Пары» загорается красная точка.
- Кнопка **«Загрузить расписание»** открывает модальное окно подключения ссылки на Google Таблицу с расписанием модуля.

### 5. Профиль
- **Личные данные**: редактирование имени, выбор учебной группы из каталога и настройка времени сна (отбой и подъём).
- **Другие дела**: список еженедельных постоянных дел с возможностью добавления, редактирования дней недели и времени, а также удаления.
- Подключение новой ссылки на расписание и выход из аккаунта.

## 4. Стек технологий и дизайн-система

### Фронтенд
- **Фреймворк**: [Next.js 16](https://nextjs.org/) (App Router, Static Export для совместимости с Tauri) + React 19 + TypeScript.
- **Стилизация и UI**: Tailwind CSS v4, `@base-ui/react`, `shadcn/ui`, иконки `lucide-react`, шрифт `Inter` (шаг сетки 4 px).
- **Состояние и работа с данными**: TanStack React Query v5, React Hook Form + Zod v4, `date-fns`.
- **Десктоп- и мобильная сборка**: [Tauri v2](https://v2.tauri.app/) (`src-tauri/`).

### Бэкенд
- **Язык и веб-фреймворк**: Python 3.12 и [FastAPI](https://fastapi.tiangolo.com/).
- **Валидация данных**: Pydantic v2.
- **Работа с базой данных**: SQLAlchemy 2.x и PostgreSQL; миграции схемы выполняются через Alembic.
- **Аутентификация**: JWT access-токены; пароли хранятся в виде хешей, а не в открытом виде.
- **Импорт расписания**: отдельный модуль `schedule_parser` для загрузки и разбора источников расписания, включая Google Таблицы.
- **Развёртывание**: Docker-образ на базе `python:3.12-slim`; при запуске контейнера сначала выполняется `alembic upgrade head`, затем запускается Uvicorn.

## 5. Архитектура бэкенда

Бэкенд предоставляет REST API для фронтенда. Основные маршруты подключены в `backend/app/main.py`:

| Модуль | Базовый маршрут | Назначение |
| :--- | :--- | :--- |
| Авторизация | `/auth` | Регистрация, вход и выдача токена доступа. |
| Профиль пользователя | `/users` | Получение и редактирование профиля через `/users/me`. |
| Дедлайны | `/deadlines` | Создание и управление заданиями, в том числе бессрочными. |
| Задачи | `/tasks` | Работа с запланированными временными слотами. |
| Разовые события | `/events` | Создание и изменение событий, привязанных к определённой дате и времени. |
| Постоянные дела | `/routines` | Повторяющиеся дела по дням недели и времени. |
| Каталог | `/faculties`, `/programs`, `/groups` | Справочники факультетов, образовательных программ и учебных групп. |
| Расписание | `/schedule` | Получение расписания занятий для выбранной учебной группы. |
| Источники расписания | `/sources` | Подключение источников расписания для импорта и последующего обновления данных. |

### База данных и миграции

- Подключение к PostgreSQL задаётся переменной окружения `DATABASE_URL`.
- SQLAlchemy используется для моделей и запросов к базе данных.
- Изменения структуры базы хранятся в `backend/migrations/versions/` и применяются Alembic.
- Dockerfile автоматически применяет миграции перед запуском API. При локальном запуске команду миграций нужно выполнить вручную.

### Обновление расписания

В `backend/schedule_parser/jobs/scheduler.py` реализован отдельный планировщик: по умолчанию он обновляет подключённые источники каждые 8 часов и ежедневно проверяет сроки действия модулей расписания. Планировщик запускается отдельным процессом и **не стартует автоматически вместе с Uvicorn** в текущей конфигурации Dockerfile. Чтобы включить периодическое обновление, запустите его отдельно из каталога `backend`:

```bash
python -m schedule_parser.jobs.scheduler
```

Для импорта Google Таблиц необходимо задать `GOOGLE_SHEETS_API_KEY`.

## 6. Запуск и разработка

### Переменные окружения

Для фронтенда по умолчанию используется API `https://personalplanner-ybpm.onrender.com`. Если необходимо указать другой адрес, создайте файл `.env.local` в корне фронтенда/проекта:

```env
NEXT_PUBLIC_API_URL=https://personalplanner-ybpm.onrender.com
```

Для бэкенда создайте `.env` с настройками подключения к PostgreSQL и авторизации. Минимально необходимы следующие переменные:

```env
DATABASE_URL=postgresql+psycopg://USER:PASSWORD@HOST:5432/DATABASE
JWT_SECRET=replace-with-a-long-random-secret
JWT_ACCESS_TOKEN_EXPIRE_MINUTES=60
JWT_ALGORITHM=HS256
```

Дополнительные параметры бэкенда:

```env
GOOGLE_SHEETS_API_KEY=your-google-sheets-api-key

CORS_ORIGINS=["http://localhost:3000", "http://tauri.localhost"]
```

### Запуск фронтенда

```bash
# Установка зависимостей
bun install

# Запуск dev-сервера (http://localhost:3000)
bun run dev

# Проверка линтером и форматирование
bun run lint
bun run fmt:check

# Сборка статического бандла Next.js
bun run build

# Запуск в окружении Tauri
bun run tauri dev
```

### Локальный запуск бэкенда

Требуется Python 3.12 или выше и доступный экземпляр PostgreSQL. Из корня репозитория выполните:

```bash
cd backend
python -m venv .venv

# Linux / macOS
source .venv/bin/activate

# Windows PowerShell: вместо предыдущей команды используйте
# .venv\Scripts\Activate.ps1

pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

После запуска API доступно по адресу `http://localhost:8000`. Интерактивная документация FastAPI: `http://localhost:8000/docs`, альтернативная документация: `http://localhost:8000/redoc`. Корневой маршрут `GET /` возвращает `{"message": "ok"}`.

### Запуск через Docker Compose

Из корня репозитория после настройки `.env` выполните:

```bash
docker compose up --build backend
```

Контейнер бэкенда слушает порт `${PORT:-8000}`. В текущем `docker-compose.yml` запускается только бэкенд; база данных подключается по `DATABASE_URL`, а встроенный сервис PostgreSQL закомментирован. Планировщик обновления расписания при необходимости также запускается отдельно.

# 📅 Planner API (Backend & Database)

Серверная часть приложения-планировщика, построенная на базе **FastAPI**, **PostgreSQL** и **SQLAlchemy**. Полностью контейнеризирована с помощью **Docker Compose** и поддерживает «горячую» перезагрузку кода на лету.

---

## 🛠 Предварительные требования

Для запуска проекта на компьютере должен быть установлен только Docker:
* [Docker Desktop](https://www.docker.com/products/docker-desktop/) (для Windows и macOS)
* Или `docker` + `docker-compose-plugin` (для Linux)

---

## 🚀 Быстрый старт

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/lghtlsss/planner
cd planner
```

### 2. Подготовьте переменные окружения

Создайте файл .env возле файла docker-compose, если нужно, добавте в него недостающие переменные.
### 3. Соберите и запустите контейнеры

Откройте ваш терминал в папке с docker-compose и выполните:

```bash
docker compose up --build
```
При первом запуске Docker автоматически:

1.  Развернёт и настроит базу данных, если это необходимо.
2.  Установит все зависимости Python.
4.  Запустит веб-сервер на порту 8000.

🌐 Полезные адреса

После успешного запуска доступны следующие интерфейсы:

|Сервис|Адрес|Описание|
| :--------------- | :---------------------------- | :-------------------------------------------------- |
|**Swagger UI**   |http://localhost:8000/docs|Интерактивная документация API (тестирование ручек)|
|**ReDoc**        |http://localhost:8000/redoc|Альтернативная документация API|
|**Health Check** |http://localhost:8000|Проверка доступности сервера (`{"message": "ok"}`)|

💻 Разработка и Hot-Reload

  - Редактирование кода: Папка ./backend проброшена внутрь контейнера. Любые
    изменения в Python-файлах вызывают автоматический мгновенный перезапуск
    сервера.
  - Добавление новых библиотек: Если вы добавили новую зависимость в
    backend/requirements.txt, пересоберите контейнер:

```bash
docker compose up --build
```
🗄 Работа с миграциями (Alembic)

  - Применение миграций: Происходит автоматически каждый раз при старте
    контейнера (alembic upgrade head).
  - Создание новой миграции: Если вы изменили модели SQLAlchemy в app/models/,
    выполните команду прямо через работающий контейнер:

```bash
docker compose exec backend alembic revision --autogenerate -m "описание_изменений"
```
Новый файл миграции сразу появится в вашей локальной папке
    backend/migrations/versions/.

🧰 Шпаргалка по командам Docker

# Запустить проект в фоновом режиме
```bash
docker compose up -d
```
# Посмотреть логи бэкенда в реальном времени
```bash
docker compose logs -f backend
```
# Остановить контейнеры
```bash
docker compose down
```
# Полный сброс базы данных
```bash
docker compose down -v
```
# Зайти в консоль внутри контейнера бэкенда
```bash
docker compose exec -it backend bash
```
